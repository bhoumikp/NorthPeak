# NorthPeak Digital

A responsive one-page agency landing page built for the **Digital Heroes Training Task**.

https://bhoumikp.github.io/NorthPeak/

## 📂 GitHub Repository

https://github.com/bhoumikp/NorthPeak

---

## 📖 Overview

NorthPeak Digital is a fictional digital agency landing page designed to showcase modern web design principles, responsive layouts, accessibility, and frontend best practices.

The website includes:

- Hero section with primary call-to-action
- Services section
- Client testimonials
- Pricing plans
- Contact form with client-side validation
- Responsive footer with required attribution

---

## ✨ Features

- Responsive design (360px, 768px, 1440px)
- Mobile-first layout
- Semantic HTML5
- Modern CSS (Flexbox & Grid)
- Vanilla JavaScript
- Dynamic rendering using JavaScript data arrays
- Client-side form validation
- Smooth scrolling navigation
- Hover interactions
- Accessible form labels and autocomplete
- Optimized Lighthouse scores

---

## 🛠 Tech Stack
